# 📉 FinRisk — Corporate Bankruptcy & Financial Distress Predictor

> An end-to-end machine learning classification system analyzing financial ratios and operational metrics to identify insolvency risk and forecast corporate bankruptcy with high precision.

## 🚀 Features

- **Financial Ratio Analysis** — Analyzes solvency, liquidity, profitability, and leverage metrics across enterprise balance sheets.
- **Imbalanced Class Handling** — Overcomes severe class disparity via SMOTE (Synthetic Minority Over-sampling Technique) and cost-sensitive loss.
- **Multi-Model Benchmark** — Trains and evaluates Logistic Regression, Decision Trees, Random Forests, and Gradient Boosting algorithms.
- **Performance Evaluation** — Thorough analysis using ROC-AUC curves, Precision-Recall trade-offs, and Confusion Matrix diagnostics.
